# Rename the Planet — make.fun entry

One funny line that renames a planet in our solar system and says why,
in a single line under 200 characters.

**The line:**

> Venus is now 'The Chronically Late Planet' because a single day there outlasts its entire year.

**Why this joke:** Venus rotates so slowly that one Venusian day (about
243 Earth days) is longer than one Venusian year (about 225 Earth days).
A planet that cannot even finish a day before its year is over is
chronically late for everything, including its own birthday.

**How it runs:** `python3 main.py` (stdlib only, deterministic) writes
the line to `/output/entry.txt`.
